# ✅ Problem Solved

## 1️⃣ LeetCode 35 - Search Insert Position

- **Difficulty:** Easy
- **Topic:** Binary Search

### 💡 Approach

- Apply Binary Search on the sorted array.
- If the target element is found, return its index.
- If the target is not present, continue narrowing the search space.
- When the search ends, `start` points to the correct insertion position, so return `start`.

### ⏱ Complexity

- **Time Complexity:** `O(log n)`
- **Space Complexity:** `O(1)`
