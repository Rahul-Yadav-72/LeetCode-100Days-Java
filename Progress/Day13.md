## 1️⃣ LeetCode 53 - Maximum Subarray

- **Difficulty:** Medium
- **Topic:** Arrays, Dynamic Programming

### 💡 Approach

- Use **Kadane's Algorithm** to find the maximum sum of a contiguous subarray.
- Traverse the array while maintaining the current subarray sum.
- Update the maximum sum whenever a larger sum is found.
- Reset the current sum to `0` whenever it becomes negative.

### ⏱ Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)`

## 2️⃣ LeetCode 75 - Sort Colors

- **Difficulty:** Medium
- **Topic:** Arrays, Two Pointers

### 💡 Approach

- Apply the **Dutch National Flag Algorithm**.
- Maintain three pointers:
  - `low` → Position for the next `0`
  - `mid` → Current element
  - `high` → Position for the next `2`
- Traverse the array once while swapping elements into their correct positions.

### ⏱ Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)`
