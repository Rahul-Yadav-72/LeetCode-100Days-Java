# ✅ Problems Solved

## 1️⃣ LeetCode 179 - Largest Number

- **Difficulty:** Medium
- **Topic:** Greedy, Sorting

### 💡 Approach

- Convert each integer into a string.
- Sort the strings using a custom comparator.
- Compare `(b + a)` and `(a + b)` to determine which order produces the larger number.
- Concatenate all sorted strings to form the largest possible number.
- Handle the edge case where all elements are `0`.

### ⏱ Complexity

- **Time Complexity:** `O(n log n)`
- **Space Complexity:** `O(n)`

---

## 2️⃣ LeetCode 2529 - Maximum Count of Positive Integer and Negative Integer

- **Difficulty:** Easy
- **Topic:** Arrays, Counting

### 💡 Approach

- Traverse the array once.
- Count the number of positive and negative integers.
- Ignore zeros.
- Return the maximum of the two counts.

### ⏱ Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)`
