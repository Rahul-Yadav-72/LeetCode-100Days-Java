# ✅ Problems Solved

## 1️⃣ LeetCode 1394 - Find Lucky Integer in an Array

- **Difficulty:** Easy
- **Topic:** Arrays, HashMap / Counting

### 💡 Approach

- Count the frequency of each integer in the array.
- Traverse the frequency map.
- If an integer is equal to its frequency, it is considered a lucky integer.
- Return the largest lucky integer if multiple exist; otherwise return `-1`.

### ⏱ Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`

---

## 2️⃣ LeetCode 704 - Binary Search

- **Difficulty:** Easy
- **Topic:** Binary Search

### 💡 Approach

- Initialize two pointers: `start` and `end`.
- Repeatedly calculate the middle index.
- If the target equals the middle element, return its index.
- If the target is smaller, search the left half.
- Otherwise, search the right half.
- Return `-1` if the target is not found.

### ⏱ Complexity

- **Time Complexity:** `O(log n)`
- **Space Complexity:** `O(1)`
