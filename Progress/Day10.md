## 1️⃣ LeetCode 33 - Search in Rotated Sorted Array

- **Difficulty:** Medium
- **Topic:** Binary Search

### 💡 Approach

- Use Binary Search to find the target in a rotated sorted array.
- Determine whether the left half or the right half is sorted.
- Check if the target lies within the sorted half.
- Continue searching in the appropriate half until the target is found or the search space becomes empty.

### ⏱ Complexity

- **Time Complexity:** `O(log n)`
- **Space Complexity:** `O(1)`

---

## 2️⃣ LeetCode 34 - Find First and Last Position of Element in Sorted Array

- **Difficulty:** Medium
- **Topic:** Binary Search

### 💡 Approach

- Perform Binary Search twice:
  - First search to find the first occurrence of the target.
  - Second search to find the last occurrence of the target.
- Store both indices in the answer array.
- Return `[-1, -1]` if the target is not present.

### ⏱ Complexity

- **Time Complexity:** `O(log n)`
- **Space Complexity:** `O(1)`
